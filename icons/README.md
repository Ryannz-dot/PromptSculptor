# Icon Generation Instructions

To generate icons for the PromptSculptor extension:

## Option 1: Use the HTML Generator (Recommended)

1. Open `generate-icons.html` in your web browser
2. Click the download button under each icon size
3. Save the files as:
   - `icon16.png`
   - `icon48.png`
   - `icon128.png`

## Option 2: Use an Online Tool

1. Go to an online icon generator like:
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/
   - https://icon.kitchen/

2. Upload a logo or create a custom icon with:
   - Purple gradient background (#8b5cf6 to #7c3aed)
   - White star/sparkle symbol in the center
   - Rounded corners

3. Generate and download the following sizes:
   - 16x16 pixels
   - 48x48 pixels
   - 128x128 pixels

## Option 3: Use Image Editing Software

Create icons in Photoshop, GIMP, or Figma with the specifications above.

## Temporary Placeholder

For testing purposes, you can temporarily use any square PNG images renamed to the correct filenames. The extension will work with placeholder icons until you create the final designs.
